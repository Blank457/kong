# 羽毛球空间

个人羽毛球训练与装备记录空间，纯前端单页应用，数据保存在浏览器本地。

## 功能

- **首页**：训练概览、今日完成度、本周打卡统计、球拍磅数等关键指标。
- **训练页**：今日训练计划打卡（步法专项、多球训练、网前技术、核心体能、对抗练习），本周七天训练日历标记。
- **装备页**：主力球拍、备用拍、球鞋、用球清单及保养贴士。

## 技术栈

- 纯原生 HTML / CSS / JavaScript，零依赖、零构建。
- Canvas 背景羽毛飘落动画，支持 `prefers-reduced-motion`。
- `localStorage` 持久化训练打卡与训练日数据。
- 响应式布局，适配桌面与移动端。

## 目录结构

```
├── index.html        首页
├── training.html     训练页
├── gear.html         装备页
├── assets/
│   ├── css/style.css 样式
│   └── js/
│       ├── store.js  本地存储
│       └── main.js   页面逻辑
```

## 运行

直接用任意静态服务器打开根目录即可，例如：

```bash
npx http-server . -p 8080
```

或直接双击 `index.html` 在浏览器打开。
