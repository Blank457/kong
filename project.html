Glass UI

为什么造这个轮子

市面上的 React 组件库要么太重（Ant Design 单包 300kb+），要么设计语言太"企业"（缺少质感），要么 a11y 是事后补的。Glass UI 想同时做到三件事：轻、美、可访问。

设计语言

所有组件共享一套玻璃拟态基础：半透明表面 + backdrop-blur + 微边框 + 环境光反射。这让组件在任何背景上都能"融入"而不是"贴上"。

可访问性

基于 Radix Primitives 构建，每个交互组件开箱即用支持键盘导航、焦点管理、aria 属性。不靠 div 模拟交互，每个组件都有正确的语义角色。

体积控制

用 esbuild 做按需导出，每个组件独立入口。Tree-shaking 后只引入用到的组件。整个 Dialog 组件 gzip 后只有 3.2kb。

组件库的体积不是看 README 写的数字，而是看你的应用打包后实际引入了多少。Glass UI 的每个组件都是独立入口，确保 tree-shaking 真正生效。

快速开始

bash 
npm install @glass-ui/react
app.tsx 
import { Dialog } from '@glass-ui/react/dialog';

export function App() {
  return (
    <Dialog>
      <Dialog.Trigger>打开</Dialog.Trigger>
      <Dialog.Content>
        <Dialog.Title>确认删除</Dialog.Title>
        <Dialog.Description>此操作不可撤销。</Dialog.Description>
      </Dialog.Content>
    </Dialog>
  );
}
